# Cheat sheet: things you can say to Claude

Open the Claude app, start a new **Code** session, and pick the
`oc-seller-finder` folder. Then just type what you want in plain words.

## Daily work

| You say | What happens |
|---|---|
| "Find sellers in Dana Point" | Gets homes, scores them, shows the best ones |
| "Open my list" | Opens the report in your browser |
| "Find emails for my top 10" | Looks up owner emails (asks you first, costs a few cents) |
| "Write emails for my top 5" | Writes personal emails and saves them as **drafts** in Gmail |
| "Check my replies" | Looks in Gmail for replies and updates each home |
| "Skip 23, it's a rental I know" | Marks home #23 as skipped, with your note |
| "Never contact 41 again" | Blocks that owner for good |

You always send the emails yourself, from Gmail. Claude never sends email.

## Change things

| You say | What happens |
|---|---|
| "Add Laguna Beach to my cities" | Updates your settings |
| "Give more points to out-of-state owners" | Changes the scoring |
| "Add condos" | Includes condos next time |
| "Make the emails shorter / warmer / more direct" | Changes how emails are written |

## Build and learn

| You say | What happens |
|---|---|
| "Can it do X?" | Claude explains and offers to build it |
| "Add a column for the year built to my report" | Claude builds it, tests it, shows you |
| "Explain how the scoring works" | A plain-words tour of the code |
| "Save my work" | Saves your changes and backs them up to GitHub |
| "Undo that" / "It was working before" | Safely goes back |

## Tips

- One thing at a time. Finish it, save it, then do the next thing.
- If you don't understand something, say "explain that simply".
- If something looks wrong, say what you expected and what you saw.
- Start a new session when you switch to a different job. It keeps Claude sharp.
